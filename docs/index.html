Subscribe in Google Calendar

  1. Right-click the feed you want above and copy the link address.
  2. In Google Calendar (web), next to Other calendars click + → From URL.
  3. Paste the link and click Add calendar.

Apple Calendar: File → New Calendar Subscription. Outlook: Add calendar → Subscribe from web.

Google refreshes subscribed calendars roughly every 12–24 h. These feeds no longer change, so there is nothing new to pick up.
